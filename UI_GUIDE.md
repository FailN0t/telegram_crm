# UI Guide

UI состоит из двух страниц:
- `/ui/auth` — авторизация MTProto.
- `/ui` — основная консоль чатов.
- `/ui/operators` — лимиты операторов.
- `/admin` — admin‑панель.

## `/ui/auth` — авторизация
### Что показывает
- Статус соединения и авторизации.
- Инструкции по входу.

### Как войти
1. Выберите аккаунт в списке **Account**.
2. Нажмите **Send code**.
3. Введите код из Telegram → **Submit code**.
4. Если включена 2FA — введите пароль → **Submit 2FA**.
5. Перейдите в `/ui`.

### Кнопки
- **Refresh status** — обновить состояние.
- **Log out** — выйти и удалить локальную сессию.

## `/ui` — консоль чатов
### Общая раскладка
- **Левый сайдбар 1**: аккаунты (переключение активного аккаунта).
- **Левый сайдбар 2**: список чатов + поиск + фильтры.
- **Центр**: диалог (история, отправка, статусы).
- **Правый сайдбар**: карточка контакта, теги, заметки, quick replies.

### Верхняя панель
- Статус системы: connection/authorization/session/anti‑spam.
- Действия: refresh, logout, переключение темы.

### Список чатов
- Поиск по чатам.
- Фильтры: `All`, `Unread`, `New`, `Errors`.
- Клик на чат — загрузка истории и карточки контакта.

### Диалог
- История сообщений, статусы: `queued`, `sent`, `failed`, `received`.
- Отправка сообщения в выбранный чат.
- Быстрые шаблоны (Quick Replies).

### Новый чат
- Можно указать `@username` или телефон.
- Первое сообщение отправляется через `Send`.

### Карточка контакта
- Имя/username/phone/chat_id.
- Теги и заметки.
- Consent/Opt‑out.
- Quiet hours + timezone.
- Кнопка **Save** сохраняет профиль.

### Журнал событий
- Ошибки отправки.
- Успешные отправки.
- Авторизация/выход.

## `/ui/operators` — лимиты операторов
### Что показывает
- Список операторов (по Basic Auth логинам).
- Статистику отправок за 1 час и 24 часа.
- Текущие лимиты (hourly/daily).

### Как обновлять лимиты
1. Откройте `/ui/operators`.
2. Измените `Display name`, `Email`, `Hourly limit`, `Daily limit`.
3. Нажмите **Save**.
4. Требуется роль `admin` в `UI_BASIC_AUTH_USERS`.

## `/admin` — admin‑панель
### Разделы
- `/admin` — сводка по аккаунтам, операторам, outbox.
- `/admin/accounts` — управление label/active для Telegram аккаунтов.
- `/admin/settings` — изменение глобальных лимитов (anti‑spam/outbox).
- `/admin/logs` — просмотр логов приложения и audit log.

### Примечания
- Для доступа нужен Basic Auth с ролью `admin`.
- Часть настроек может требовать рестарта worker для применения.
- В `/admin/settings` есть блок AmoCRM OAuth с кнопкой Connect (нужны `AMOCRM_*` переменные).

## Горячие клавиши
- `Ctrl/⌘ + Enter` — отправка сообщения.
- `Ctrl/⌘ + K` — фокус на поиск.
- `Ctrl/⌘ + Shift + N` — новый чат.
- `Esc` — снять выбор чата.

## Примечания
- Мульти‑аккаунты работают: переключайте аккаунт в левом сайдбаре и на `/ui/auth`.
- UI получает обновления через SSE (`/api/ui/stream`).
