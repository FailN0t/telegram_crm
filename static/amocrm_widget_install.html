📱 Установка Telegram Widget для AmoCRM

Интеграция Telegram с AmoCRM - общайтесь с клиентами прямо из карточки контакта

⚠️ Внимание: Для установки widget необходимы права администратора в AmoCRM.

1Регистрация интеграции в AmoCRM

Перейдите в раздел Настройки → Интеграции → Создать интеграцию в вашем аккаунте AmoCRM.

Заполните основную информацию:

Название: Telegram CRM
Тип: Widget (виджет)

2Настройка OAuth

В разделе OAuth настройте следующие параметры:

Redirect URI:
Client ID: Скопируйте после создания
Client Secret: Скопируйте после создания

✅ Способ 1: Загрузка виджета в AmoCRM (рекомендуется)

3Скачать и установить виджет

Виджет позволяет встроить чат Telegram прямо в карточку контакта.

📥 Скачать виджет (telegram_crm_widget.zip)

Установка:

  1. Перейдите в AmoCRM: Настройки → API → Виджеты
  2. Нажмите кнопку "Добавить виджет" (внизу страницы)
  3. Загрузите скачанный файл telegram_crm_widget.zip
  4. Нажмите "Установить"
  5. Виджет появится в карточках контактов автоматически

💡 Примечание: После установки виджет будет автоматически отображаться в правой панели карточек контактов, сделок и компаний.

✅ Способ 2: Прямой iframe (альтернатива)

5Настройка Webhook

Для получения событий от AmoCRM настройте webhook:

Webhook URL:

Включите события:

  • notes.add (примечания)
  • contacts.update (обновление контактов)

6Настройка пользовательских полей

Создайте следующие поля в контактах AmoCRM:

telegram_username: Текстовое поле для @username
telegram_chat_id: Числовое поле для ID чата
telegram_consent: Переключатель (согласие на рассылку)

✅ Готово! После завершения настройки widget появится в карточках контактов на отдельной вкладке "Telegram".

Как использовать

1. Откройте карточку контакта в AmoCRM

2. Перейдите на вкладку "Telegram"

3. Отправляйте сообщения клиентам прямо из карточки

4. Входящие сообщения будут автоматически отображаться в истории
