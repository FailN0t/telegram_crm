📱 Telegram CRM для AmoCRM

Интеграция Telegram с AmoCRM - отправляйте сообщения клиентам и получайте ответы

✅ Текущий статус: Интеграция работает! Вы можете отправлять сообщения через примечания с тегом #telegram прямо сейчас.

⚠️ Важно: Встраивание виджета в карточку контакта (как у Radist/Wazzup) требует публикации в маркетплейс AmoCRM или наличия раздела "API → Виджеты" в вашем аккаунте.

✅ СПОСОБ 1: Отправка через примечания (работает СЕЙЧАС)

1Убедитесь, что интеграция OAuth настроена

Если вы еще не настроили OAuth интеграцию:

  1. Перейдите в Настройки → Интеграции → Создать интеграцию
  2. Укажите тип: Приватная интеграция (OAuth)
  3. В разделе OAuth укажите Redirect URI:
Redirect URI:

После создания скопируйте Client ID и Client Secret из раздела "Ключи и доступы".

2Настройте Webhook для получения примечаний

В интеграции AmoCRM в разделе "Ключи и доступы" настройте webhook:

Webhook URL:

Включите события:

  • notes.add - добавление примечаний
  • contacts.update - обновление контактов (опционально)

3Создайте пользовательские поля в контактах

Перейдите в Настройки → Настройка → Контакты и создайте поля:

telegram_username: Текст (для @username)
telegram_chat_id: Число (для ID чата)
telegram_consent: Переключатель (согласие на рассылку)

4Начните использовать!

Как отправить сообщение клиенту:

  1. Откройте карточку контакта в AmoCRM
  2. Убедитесь, что заполнены поля telegram_username или telegram_chat_id
  3. Добавьте примечание с тегом #telegram:
Привет! Как дела? #telegram

Входящие сообщения: Когда клиент ответит в Telegram, его сообщение автоматически появится в примечаниях контакта.

✅ Готово! Теперь вы можете общаться с клиентами через Telegram прямо из AmoCRM.

⚠️ СПОСОБ 2: Встраивание виджета в карточку (требует дополнительной настройки)

Встраивание виджета как у Radist/Wazzup/i2crm

Чтобы получить полноценный чат прямо в карточке контакта (как у популярных интеграций), есть три варианта:

AВариант 1: Раздел "API → Виджеты"

Если в вашем AmoCRM есть раздел "API → Виджеты":

📥 Скачать виджет (telegram_crm_widget.zip)
  1. Скачайте виджет по кнопке выше
  2. Перейдите в AmoCRM: Настройки → API → Виджеты
  3. Нажмите кнопку "Добавить виджет" (внизу страницы)
  4. Загрузите файл telegram_crm_widget.zip
  5. Нажмите "Установить"

⚠️ Важно: Раздел "API → Виджеты" доступен не во всех типах интеграций. Если вы не видите этот раздел, используйте Вариант 2.

BВариант 2: Публикация в маркетплейс AmoCRM

Для полноценного встраивания как у Radist/Wazzup:

  1. Подать интеграцию на публикацию в маркетплейс AmoCRM
  2. Пройти модерацию кода и функционала (2-4 недели)
  3. После публикации виджет будет доступен для установки всем пользователям

Документация: https://www.amocrm.ru/developers/content/integrations/marketplace

💡 Примечание: Это единственный способ получить точно такую же интеграцию, как у Radist, Wazzup, i2crm. Все эти сервисы прошли публикацию в маркетплейс.

CВариант 3: Прямой URL виджета

Временное решение: открывать чат в отдельной вкладке браузера

URL для открытия:

Замените {{contact.id}} на реальный ID контакта и откройте URL в браузере.

⚠️ Ограничение: Виджет не будет встроен в карточку контакта, только как отдельная страница.

Что выбрать?

  • Для немедленного использования: Способ 1 (примечания с #telegram) - работает прямо сейчас
  • Если есть раздел "API → Виджеты": Вариант A - установка zip-файла
  • Для полноценной интеграции как у Radist: Вариант B - публикация в маркетплейс
  • Для тестирования: Вариант C - прямой URL

✅ Рекомендация: Начните с примечаний (#telegram) прямо сейчас, а параллельно подайте заявку на публикацию в маркетплейс для получения полноценного виджета.
